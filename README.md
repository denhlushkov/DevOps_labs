## Варіант індивідуального завдання
Для номера залікової книжки **N = 7**:
* **V2** = (7 % 2) + 1 = 2 => СУБД **PostgreSQL**, конфігурація через файл `/etc/devops_labs/config.json`.
* **V3** = (7 % 3) + 1 = 2 => Тематика застосунку: **Task Tracker**.
* **V5** = (7 % 5) + 1 = 3 => Порт застосунку: **3000**.

## Документація по розробленому веб-застосунку
Застосунок реалізовано на базі Node.js (Express.js) та драйвера `pg` для прямої взаємодії з PostgreSQL. Підтримує конфігурування через зовнішній JSON-файл та реалізує механізм **Systemd Socket Activation** (слухає дескриптор `3`, переданий від systemd).

### API Ендпоінти:
* `GET /` — Повертає plain HTML сторінку зі списком доступних бізнес-ендпоінтів (доступний тільки для `text/html`).
* `GET /tasks` — Повертає список усіх задач. Якщо заголовок `Accept: text/html` — віддає HTML-таблицю. Якщо `Accept: application/json` — віддає JSON.
* `POST /tasks` — Створення задачі. Приймає параметр `title`.
* `POST /tasks/<id>/done` — Зміна статусу задачі на "виконано".
* `GET /health/alive` та `GET /health/ready` — Внутрішні ендпоінти перевірки стану системи.

## Інструкція з розгортання

### 1. Вимоги до віртуальної машини
* **Базовий образ:** Офіційний ISO-образ Ubuntu Server 24.04 LTS.
* **Ресурси:** 1 vCPU, 2 GB RAM, 20 GB Disk Space.
* **Мережеві налаштування:** Мережевий міст (Bridged Adapter) для отримання унікальної IP-адреси в локальній мережі.

### 2. Кредишнли за замовчуванням (до запуску автоматизації)
Під час встановлення ОС створюється дефолтний користувач ubuntu із доступом до SSH.

### 3. Запуск автоматизації
Зайдіть на чисту ВМ по SSH, клонуйте репозиторій та запустіть скрипт:
```bash
git clone <url_репозиторію>
cd devops_labs
chmod +x scripts/setup.sh
